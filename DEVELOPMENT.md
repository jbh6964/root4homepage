# Root4 prototype

Node.js 24 / npm 11. React 19 + Vite 7. No secrets, backend or external service is required. Fonts and artwork are served locally.

```sh
cd /workspace/root4homepage
npm ci --cache /tmp/root4-npm-cache
npm run dev -- --port 5173
```

Production: `npm run build`, then `npm run preview -- --port 4173`. Vercel uses `vercel.json` and deploys the connected `main` branch.

- Content: `src/data.js`. Project artwork sources: `public/projects/*.svg`; optimized 2400px-wide previews (height follows the source aspect ratio): matching `.webp` files. Update both when replacing a project image. The TV and commerce artwork contains generated concept photography, not customer material.
- `src/ScrollGallery.jsx` owns one sticky viewport for the desktop homepage. All projects, About, Lab and Contact share the same native scroll timeline. There is no handoff to ordinary document scrolling after the gallery, wheel interception or forced snap.
- Opening showcase: Connect is the large central work; Fino and Ondo are readable supporting works. Orbit, Form & Field and Wayve are clipped at the edges. There are no duplicate detail fragments or oversized background lettering competing with the work. Existing pointer depth/tilt is retained, with no new pointer handlers. Scroll expands Connect and reveals the same six projects in the same order. Reverse scrolling reverses the sequence.
- Project images have separate art directions: telecom service/plan discovery, finance balances/cash flow, cinematic TV discovery and focus, enterprise workflow board, product-led commerce, and a mobility route workspace. SVG boards and optimized WebP previews are replaced together. Original concept UI artwork is generated by `node scripts/create-project-art.mjs`; its two generated concept photographs are in `public/projects/media/`. No customer work or company performance is claimed.
- `opening` metadata in `src/data.js` enables ratio-specific `{id}-opening.svg` / `.webp` covers. The lead uses one 1600×970 board throughout entry, so there is no crossfade of overlapping text. Finance, TV and product previews have their own crop/composition; two edge previews retain the unframed board. The opening layer compensates for the existing frame scale and stays opaque while its frame fades with the existing `--overview-opacity`, then hides before the next project enters. Full project art, inspection crops and detail articles use the regular assets, with a safe area inside the unchanged camera overscan. `imageSize` overrides the default 1600×1100 intrinsic dimensions where needed. The original project boards and opening previews preserve their aspect ratios. Under reduced motion/mobile, only regular artwork is rendered. Opening pose coordinates are in `composition`; only the opening placement, layers and cover blending changed. The scroll constants, 115ms damping, expansion/exit equations, final target rectangle, handlers and chapter choreography remain unchanged.
- About: text, background typography, strategy document, wireframe and process rows have different parallax amounts. Process buttons update the strategy document on hover, focus and click.
- Lab: three overlapping, independently moving editorial notes; hover and focus raise a note for reading. Each opens its example article.
- Contact: independent type, symbol and background motion; inquiry opens an explicit demo with a copyable template. No message is sent.
- Header navigation uses real document links: `/work`, `/about`, `/lab`, `/contact`; the Root4 logo returns to `/`. Each page supports direct visits, refresh, new tabs and browser navigation. `src/Pages.jsx` resolves these routes; `vercel.json` rewrites them to the Vite entry. Project articles use `/work/:id`, notes use `/lab/:slug`. Homepage scene controls still seek the timeline through `navigationRef`. Legacy homepage section hashes remain supported.
- Browser Back restores document scroll, including the long homepage timeline. A pagehide snapshot supplements native scroll restoration, and `root4:restore` synchronizes the gallery immediately. Work filters persist in the URL (`/work?type=app`). Shared article content lives in `src/DetailBody.jsx`; desktop homepage dialogs retain their existing focus and scroll behavior.
- Hidden projects and chapters are inert and excluded from accessibility navigation. Detail dialogs support focus trapping, Escape, browser back, and focus/scroll restoration.
- Under 768px, or with reduced motion enabled, the same content becomes a normal accessible document. Mobile has one project column. Touch has no custom pointer. Idle artwork does not run perpetual animations.
- Pacing and motion profiles live in `src/motion.js`. Each project has a 0.9-unit entry followed by a 1.35-unit dwell/inspection interval before the next entry. Separate overview breathing room, a 115ms visual damping time constant and longer chapter reading intervals keep normal wheel input from immediately advancing past a scene. Native scrolling remains unmodified.
- `src/FeatureDetail.jsx` presents three scope-specific detail crops for each project. Scroll advances them automatically; hover, focus and click can inspect a chosen point. Hovering the main UI connects a reticle to the detail magnifier. Camera pan/zoom profiles vary by project; TV has aperture mattes, commerce has material swatches, and mobility has a scroll-drawn route. Progress indicators show the current project's reading interval.
- About's four process stages advance with scroll and remain selectable. Lab's notes unfold separately and fully open on hover/focus. Contact reveals two title lines, supporting copy, inquiry action and the typographic seal in distinct beats. Standalone About and Contact reuse the fully readable static scenes; About retains manual process controls.
- Timeline geometry and styles live in `src/ScrollGallery.jsx` and `src/gallery.css`; opening art direction is isolated in `src/opening.css`; narrative content and process interaction live in `src/StoryContent.jsx`. The desktop composition is specifically designed for six projects; review the composition when adding more.
